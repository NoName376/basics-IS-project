## 3. Если спросят

**— Почему PostgreSQL, а не SQLite?**
«SQLite остался только как офлайн-режим для проверки. Рабочая база — PostgreSQL 18:
та же схема, те же запросы, переключение одной переменной `DATABASE_URL`. Тесты Нурбола
проходят на обеих.»

**— Где хранятся пароли?**
«PBKDF2-HMAC-SHA256, 260 000 итераций, своя соль у каждого. В базе только хеш, сравнение
за постоянное время. Даже пользователи из скрипта Алибека уже с настоящими хешами.»

**— Почему суммы в копейках?**
«Деньги — целые числа (`amount_cents BIGINT`). Во float 0.1 + 0.2 ≠ 0.3, и семейный бюджет
начал бы расходиться. Нурбол нашёл это как дефект D-06, у нас закрыто проверкой и тестом.»

**— Что будет при одновременной записи?**
«Каждый показ экрана перечитывает базу, запись — одна короткая SQL-команда. Второй
пользователь увидит актуальный баланс при следующем действии.»

**— Что сделал лично ты?**
«Приложение: пять экранов, вход и роли, добавление операций, история, лимиты, CSV.
Плюс интеграция: переключил проект на PostgreSQL, собрал базу из скрипта Алибека и прогнал
тесты Нурбола — 36 из 36.»

**— Кто что делал в команде?**
«Ali — требования и use cases, Alibek — схема и данные PostgreSQL, Abdulaziz — архитектура
и безопасность, Нурбол — 36 приёмочных кейсов и аналитика, я — приложение и интеграция.»

## 4. Если что-то не так

| Симптом | Что делать |
|---|---|
| В сайдбаре `Backend: SQLite` | Нет `postgres_url.txt` в папке проекта или в нём неверный пароль |
| `connection refused` | Служба PostgreSQL не запущена: `services.msc` → `postgresql-x64-18` → Запустить |
| `password authentication failed` | Пароль в `postgres_url.txt` не тот; текущий — `postgres` |
| Порт 8501 занят | `python -m streamlit run app.py --server.port 8502` |
| Приложение не стартует | Запусти `CHECK.bat`: 34 теста + 10 проверок — это тоже доказательство |
| Данные «поплыли» после репетиции | `set /p DATABASE_URL=<postgres_url.txt` затем `python seed_demo.py --reset` |
| Показываешь на другом ноутбуке | Скопируй папку, поставь PostgreSQL, `SETUP_POSTGRES.bat`, `START.bat` |
