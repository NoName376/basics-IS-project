## Что это не покрывает

- перезапуск на PostgreSQL (ждёт схему от Алибека);
- реальных пользователей: сценарии исполнены тестовым драйвером, а не человеком;
- мобильную вёрстку и доступность.

## Как перепроверить после новой сборки

```bat
set PYTHONPATH=C:\path\to\streamlit-deps
set FBT_APP=C:\path\to\Family_Budget_Tracker_Arman
cd %FBT_APP%
python seed_demo.py
python ..\ui_check.py
```

`ui_check.py` печатает 18 строк PASS/FAIL и пишет `out/team_ui_results.json`; таблицу выше
можно пересобрать по нему за минуту.
