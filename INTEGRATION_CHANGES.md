## Что важно помнить при переносе

- Файлы чеков лежат в `data/receipts/` — при копировании или бэкапе приложения копировать
  **вместе с базой**, иначе в базе будут записи без файлов.
- `data/receipts/` нельзя отдавать как статику веб-сервера: доступ только через приложение.
- При удалении транзакции запись чека удаляется каскадом, а файл на диске остаётся —
  это известное ограничение, записано у Алибека.
- Демо-база в архиве уже с применённой миграцией: 113 транзакций, 0 чеков.

## Откат (если понадобится)

```sql
DROP TABLE IF EXISTS receipts;
```

и удалить из `app.py` вставленный блок и импорт; папку `receipt_feature/` можно оставить —
без миграции она просто не используется.
